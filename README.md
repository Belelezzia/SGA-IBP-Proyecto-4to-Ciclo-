# SGA-IBP-Proyecto-4to-Ciclo-

Cursos: Análisis y Diseño de Sistemas

Este proyecto es acerca de un SGA(Sistema de Gestión Académico) para el Instituto El Buen Pastor. El objetivo de este es lograr que la información y procesos de la institución se establezcan en un solo lugar, es decir tener un solo punto de entrada y salida de datos tanto para los alumnos, docentes y administrativos. Otro de sus objetivos es disminuir la necesidad de presencialidad, llevar los procesos que normalmente las personas realizan como solicitudes de constancias, documentos, cambios de turno y demás a un ámbito virtual, todo desde la plataforma. Por otro lado, que está relacionado con el objetivo de disminuir la presencialidad, la matrícula virtual es el cambio/objetivo más importante que tiene este sistema, lograr que tanto las personas interesadas en el instituto y los alumnos puedan realizar su matrícula de manera online, fácil y rápida justo como en las universidades se realiza. 

El prototipo inicial de este proyecto será realizado en vb.net usando winforms junto a mssql. Más tarde será llevado a la web (aún no se definen las tecnologías).
